# Digital-Diary-Notes-manager
A digital diary is a simple way to maintain personal notes in an organized form. This project converts the basic diary process into a console-based application. The user interacts with the program through a numbered menu. Each note contains a date and text, while its displayed note number is assigned according to its position in the saved list.
